# phmdc：PHM2019 铝搭接件（外部标定平台）

补上另外两个平台缺的一块：**损伤的定量真值**。PHM2019 数据集（*Fatigue Crack Growth in Aluminum Lap-Joint*）
提供光学实测的裂纹长度（mm），用来回答「这个损伤指标到底对不对」——这是无真值数据永远答不了的问题。

## 1. 数据

| 项 | 内容 |
| --- | --- |
| 试件 | **8 件**铝搭接件（T1–T8），铆接，疲劳裂纹扩展 |
| 传感 | 单对压电换能器，主动 Lamb 波，**20 MHz / 4000 点 / 200 µs** 原始波形 |
| 真值 | 逐测量的**裂纹长度 mm**（光学） |
| 锚 | 精确循环数 + 官方训练/验证划分 |
| 规模 | 每件 12 次测量，共 96 组波形 |

三个必须先知道的事实：

1. **T7 / T8 带完整真值**（官方说明写的是"不给"，实测有）——所以它们可以当验证集；
2. **没有 `Baseline`（cycle = 0）文件夹**，健康原点靠首次测量近似；
3. **`time` 列不可直接用**：94 个文件里 **92 个**被表格软件量化成科学计数法，需按 `t[i] = i × 5×10⁻⁸ s` 重建。

## 2. 与另外两个平台的关系

| 它有的 | 代价 |
| --- | --- |
| ✅ 原始波形（可做波形级模型） | ❌ 铝 / 铆接 / Lamb 波 ≠ 复材 / 加筋 / AE |
| ✅ 定量真值（裂纹长度 mm） | ❌ 仅 8 件 |
| ✅ 精确循环锚 + 官方划分 | ❌ 单对传感器 ⇒ **无定位能力** |

⇒ 它是**方法标定**平台，不能用来改进 `l1` 的结论，也不填补 ReMAP 的 NDT 真值缺口。

## 3. 做法

| 步 | 内容 |
| --- | --- |
| Step 0 | 数据规整 + 8 项核对：`time` 重建、带通滤波（100–300 kHz）、噪声下界标定、可用性复审 |
| Step 1 | 32 个特征 + LOSO 8 折 + 10 个对照臂（含"只看一个波形"的退化臂） |
| Step 2 | 波形级深度学习：1D / STFT × 单双通道 × 两种参考口径，锁定 cuDNN 确定性 |
| 外推 | T7–T8 用前半段预测后半段；增长律按视界分层；等损伤当量换算；健康原点锚定 |
| 统计验证 | 标签置换检验、不确定性量化、配对检验、第二通道消融（4 个无信息对照） |

## 4. 结果

| 项 | 结果 |
| --- | --- |
| 特征基线（线性 + 单调约束） | RMSE **1.501 mm**，MAE 1.233，折内 ρ 0.928 |
| 随机森林 + 约束 | 折内 ρ **0.970**（量程 0–7.46 mm） |
| 波形 CNN（双通道）+ 约束 | RMSE **1.692 mm**，MAE 1.410，零裂纹误报 **24%** |
| 外推（T7 等幅→等幅） | RMSE **0.668 / 0.830 mm**，可用 |
| 外推（T8） | **不可验证**（视界超出自检极限 1.8 倍） |
| 带通滤波的效果 | 重复性 corr 0.9545 → **0.9985**，relRMS 差 33.5% → 5.6% |
| 噪声下界 | **6%**（此后作为"是否真检出损伤"的硬标尺） |
| 置换检验 | 真实指标全部低于零分布最小值（特征级 z = 4.21；CNN 级 z = 4.78） |
| 双通道消融 | 真实零裂纹误报 24%，四个无信息对照全部回到 **81–88%**（零重叠） |

## 5. 三条可复用的方法学结论

1. **对比 DL 与特征工程必须先保证信息对等**。特征臂能看到健康基线，单通道 CNN 只看到一个波形；
   补上"相对参考波形的差值"通道后 RMSE 2.084 → **1.692**、零裂纹误报 88% → **24%**。
   否则"DL 更差"只反映输入设计缺陷。
2. **增长律选型要按视界分层**：短视界选出的 Paris 律在长视界上会爆炸（T8 即此）。
3. **物理约束层（保序投影 + 非负）在两族模型上都有效**，且**降低** RMSE——本数据的裂纹确实单调增长，
   约束剔掉的是模型抖动。投影只用循环数排序、不用标签，不构成泄漏。

## 6. 边界

- 这**不是精度验证**，对外只能说：方法在**有真值**的平台上被标定、在无真值数据上被统计验证。
- 单对传感器 ⇒ 无定位；8 件 ⇒ 结论只到"方法可行"，不做跨工况外推。
- 铝 / 铆接 / Lamb 波与复材加筋板物理不同，**不改变 `l1` 的任何结论**。

## 7. 怎么跑

```bat
cd phmdc
python run.py --list                       rem 任务矩阵
python run.py --task step0                 rem 数据规整 → labels.csv / index.csv
python run.py --task step1                 rem 特征 + LOSO
python run.py --task step2                 rem 波形级模型（需 torch）
python run.py --task step3                 rem 外推 / 预后
python run.py --task step4 step5           rem 置换检验 / 不确定性
```

`--task` 可给多个；`--dry-run` 只打印命令；`--` 之后的参数透传给底层脚本。

产物在 `phmdc/results/`。全部实验记录（含被否掉的路线与逐配置结果）见 `docs/details.md` 附录 D。
