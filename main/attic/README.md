# main/attic：已归档的评估链路

这里放**不在主路径上**的旧代码，只为让早先的结论仍可复算、可查证。**任何入口都不调用它们**，
`run.py` 里也没有对应任务。

| 文件 | 原用途 |
| --- | --- |
| `pipeline.py` | 主流程三段：`prepare`（对齐 / 弱标签）、`evaluate`（损伤度 + 分级）、`robust`（灵敏度 / LOSO / 消融 / 统计） |
| `verify.py` | 验证层 7 个子命令：基线对照、LOSO、标签审计、AE 逐列对照、分级闸门、源融合、候选体检 |
| `export_dashboard.py` | 旧看板导出（只在既有包上打补丁，已被 `cdio_baseline/build_dashboard_all.py` 取代） |
| `eval_common.py` | 上述脚本共用的参数表与指标库 |
| `probes/` | 一次性诊断脚本（标签口径、早期报警、单源对照、应变对照） |

## 为什么不在主路径

主样本的累积 AE 能量与寿命近似线性（`u@90% = 0.90`、`R² = 0.9999`），它是**时钟**而不是损伤计。
建立在其上的弱标签 `b1/b2/b3`、由它算出的偏差与 A/E/D/N 分级、以及依赖这些的基线对照与 LOSO，
**锚点不确定度大于分级带宽**，结论不可辨识，因此整体下线。

现在的交付只有一条：`cdio_baseline/` 的累积能量寿命百分比（作为零损伤信息基线）。
口径说明见仓库根的 [`当前结论与口径.md`](../../当前结论与口径.md)。
