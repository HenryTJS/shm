# 能力边界与失败方法

---

**A 主样本（016–020）—— 不能做什么**

1. ❌ **不能做 RUL**。
   ① D 没有渐变窗口：4/5 组在 1–2 个块内从 0.30 跳到 0.85 ⇒ **饱和平台零分辨率**；`D≥0.85` 后剩余寿命仍有 **5.0%–27.1%（5.4 倍差异）**。
   ② 早期无信息：`e_full` 抬升只占全寿命 6–10 块（5–14%）。
   ③ N=5，严格同工况仅 4 组。
   ④ 主源特性受限（AE 无时间戳、单通道）。
   ⇒ **替代交付**：预警提前量分析（lead 13.1–52.1%）+ 检测后剩余寿命**区间**估计。
2. ❌ **不能声称"精度已被验证"** —— 本项目最大的诚实边界。
   `b2` 由**同一批信号**（AE 累积能量 + 应变 std 发散）生成，`|t25 − b2|` 均值仅 **1.68、最大 2.30 个百分点**
   ⇒ `err = t_warn − b2` 的"高精度"有相当部分来自**标签与检测器锁在同一条曲线上**。
   ⇒ 只能声称「方法在**有真值**的平台上被**标定**、在**无真值**数据上被**统计验证**」，**不能**写"精度已被验证"。
   把"自洽"变成"验证"需要**外部真值锚**（真实断裂时刻 / NDT / 视觉），**本项目无此数据，已定案不追查**。
3. ❌ **不能做分级时间梯度（仅 016 有）**。
   闸门 `L2/L3 = max(D 达阈, 刚度达阈)` **只能推迟级别、不能提前**
   ⇒ 019 的刚度证据（57.0%）早于 AE 检测（78.8%）却无法形成梯度。
   改"各级独立触发"可救 016/019，但代价是 **L1 不再由声发射独占定义**，与"AE 为主源"的架构口径冲突。
4. ❌ **不能用多源融合口径交付**。
   泛化组 023/024/025 上，交付的 `('ae','strain')` 口径把预警**大幅提前**（024：71.4 → **30.6**；025：68.0 → **21.6**），
   而 AE 单源与物理事件位置吻合。
   机制：024/025 的应变通道**未解调（RAW）**，块 std 随寿命单调漂移（024 实测 0.22 → 11.7，**53 倍**）→ `e_strain` 提前越阈。
   ⇒ 在主样本上"无收益"、在泛化组上"有害" ⇒ **AE 单源是必要条件，不是偏好**。
5. ❌ **不能做 AE 事件速率类指标，不能做 TDOA 定位**。
   主样本 AE **无到达时间**（事件时间由 `np.linspace` 均匀生成），且**单通道**；016 另丢失 37% 事件。
6. ❌ **不能用未解调通道的幅值绝对值**。
   载荷 5 Hz + 采样 10 Hz ⇒ 每周期恰好 2 点，未解调通道交替采到峰/谷。
   判别量 `alt = mean|Δx₁|/mean|Δx₂|`：**26 通道中仅 016 应变已解调（`alt=0.94`）**，其余 25 个（含全部光纤）`alt=4.9–352`。
   用错会测到直流漂移（018 误用块均值 → 假的"+57% 退化"）。
7. ❌ **不能判定 025/026 早爆是否为误报**。
   `weak_labels/labels_summary.csv` **只覆盖 016–020**，023–026 无 `b2`，只能按形态判读。
   026 的早爆来自 `e_dmg`(13.7%) / `e_full`(13.9%)，与形状证据无关，**未解决**。
8. ❌ **不能做仿真**。
   数据是供应商导出的 25 项统计特征（**无波形 / 无时间戳 / 无通道**），与仿真输出的物理场格式不兼容；
   技术可行的两项（2D 弹性波 FDTD、加筋条导波）都依赖损伤真值，而**无 NDT 成像数据**。
9. ❌ **不能做定位**（主样本无此能力）。`agent` 中主样本**须显式声明不可定位**（PhysGuard 规则 P15）。
10. ❌ **015 与 021 不能纳入交付与大屏**。
    015 时间列/采样不可识别（事前判据 P1 不通过）；
    021 在 **5.1%** 就报警而唯一突出事件在 33.2%，且它是**全表唯一"所有方法都过早"**的组（B1 +23 / B3 +16 / 本项目 +28）
    —— 物理上就没有可用的锚。
    ⇒ 大屏纳入 **11 组 = 016-020 + 022-027**。

**A 主样本（016–020）—— 哪些方法不行**

- **5 个 RUL 特征族**（AE 形状 b 值 / amp 分位 / DFOS 峰位 / DFOS 幅值 / hit_rate）：❌ 均不改善 —— 单调性 ρ 正负混杂（如 b 值 ρ = −0.62–0.63）。
- **证据层多源融合**：❌ 无收益（泛化组上**有害**）—— 主源饱和 ⇒ 降权辅助源在 `max` 下永不生效；RAW 应变漂移会提前越阈。
- **`e_shape` 升为默认**：⚠️ 未采纳（默认关）—— 需先定 `shape_w`（0.6 沿用 `estrain_w` 的约定，**有 9 组过拟合风险**）；且 `w=1.0` 时 9 组 `D_end` 全饱和、跨试件区分度归零。
- **`e_dmg` 作为独立证据**：❌ 已冗余 —— 消融 `no_dmg` 仍 5/5 级 A ⇒ 已被 `PeakFactor` 取代；而 `e_full` 仍不可替代。
- **孤立爆发门控（burst guard）**：❌ 无效，**已撤回** —— 三档 cap（10⁴/10⁵/10⁶）对 12 组的 D/t_warn/t85 **全部无影响**：参考值取"最近 60 块 p75"被磨合期高能块污染（026 前 20 块 300–756，中段仅 0.003 → p75≈736 → cap≈7×10⁶，晚期爆发 2948 根本截不到）。**更重要的修正**："峰/中位 10⁶"是**中位≈0 造成的假象** —— 026 的爆发只是它自己磨合期水平的 4 倍。
- **`ready_mode='auto'` 修 021**：⚠️ 有改善但不够 —— t_warn 5.1% → 11.4%，仍远早于真实的 33.2%。
- **物理约束层（保序投影）**：❌ **收益为 0** —— A 仅 0.14% 违例、B/C 严格单调；投影**不改变任何一个预警时刻**，属恒等变换（见〈跨数据集 —— 对外表述红线〉）。
- **DFOS `_peak` / `_amp` / 空间峰位迁移口径**：❌ 证伪 —— `_peak`：1 Hz 采样 vs 2 Hz 加载**欠采样** → 相位混叠；`_amp`：ρ = −0.53–0.23；峰位：ρ = −0.574–0.339。
- **用 DFOS 交叉验证 RA–AF**：❌ 不成立 —— 趋势量 ρ ≈ −0.03 ⇒ 二者**互补而非互证**（测的不是同一件事）。
- **`WaveformFactor` 列**：❌ 完全无效 —— 025 `D_end` 仍 0.202，与筛查预测一致。

**B L1 一批（4 组）—— 不能做什么**

1. ❌ **不能做 RUL**。
   与 A 同机理：**4/4 组皆为 latch 阶跃** —— `t25→t55` 与 `t55→t85` 各仅跨 **1–2 个块**（1 块 = 5000 cycle）
   ⇒ **无可外推的渐变段**；且 N=4。
   ⚠️ 本条为**机理判定、非实测**（`rul_feasibility.py` 只覆盖二批，一批**未单独跑 LOSO**）。
2. ❌ **不能把定位结论外推到 Y 方向**（见〈C L1 二批 —— 不能做什么〉②）。
   且**一批的 AE 声速不可信**：PDF 自述为 after-failure 测量 ⇒ `ae_locate.py` 对一批只能用缺省值。
3. ❌ **不能靠 FBG 单源判断 L1-04**。
   其应变几乎**零漂移（−0.2 µε）→ HI_end 仅 0.721** —— 这才是 L1-04 的固有难点（与 AE 侧无关）。
4. ❌ **不能用 DFOS 块级 HI 单独做预警**。
   现"归一 + 单调包络"口径会**把早期局部噪声一次锁定** ⇒ **阈达时间偏早**；修法应改为**峰值增长率**（未做）。
5. ❌ **不能做"两个脚本各算一遍同一个物理量"**。
   刚度阈值时刻曾出过错（018 的 L≥10% 曾报 1.4%，官方是 95.7%）。
   现采用与官方逐项一致的口径并**内置自动对账**（`main/candidate_check.py` 每次运行自动与 `grade_stiff_traj.csv` 对账，漂开就报）。
   **一般化教训**：两个产物只要都能被引用，就必须有一条**自动对账**把它们绑住。

**B L1 一批（4 组）—— 哪些方法不行**

- **`mean` 融合**：⚠️ 2/4 —— 稀释，单源弱证据被平均掉。
- **`min` 融合**：❌ 0/4 —— 要求**双证据互证**，四组全未达。
- **论文 Level 3b 脱粘判据**：❌ 未复现 —— 判据与实际脱粘演化不符（原因有定量解释）。
- **论文 Level 2 应变定位判据**：❌ 不可用 —— 改用替代判据。
- **DFOS 块级 HI 做预警**：⚠️ 不宜 —— 单调包络把早期噪声一次锁定 → 阈达偏早。

**C L1 二批（9 组）—— 不能做什么**

1. ❌ **不能做「跨试件统一阈值的在线预警」**（核心一条）。
   **四条独立路径一致失败**：

   - **AE 累积量（`cum_hits`）**：随寿命演化 ✅ 强（Mon 0.955），但跨试件 ❌ **12.8×**（窗口径 **384×**）⇒ 只能离线复评。
   - **DFOS `local`（4 口径）**：随寿命 ❌ 弱（≈15–20% 增长），跨试件 ❌ 路径不可比（早期 **190×**；端点 1.18–1.25×）⇒ 无可用交付。
   - **AE × DFOS 融合**：❌ 退化（只做加权平均，未引入新信息），融合后仍不可比。
   - **严重度分工（DFOS 严重度 + AE 进度）**：❌ 已证伪（**ρ = −0.283**；分级一致 **3/9 = 随机**）。

   **根本原因（一句话）**：**AE 活动度本身的跨试件变异达数个数量级，且 AE 阈值/增益跨 campaign 不同**
   ⇒ 任何"用历史试件标定的绝对阈值"注定失效。
   **关键数字**：剔除 3 组有异常的（L1-52/54/59）后，剩 6 组在**失效时刻**的 `win10_hits` 仍跨 **384 倍（2.6 个数量级）**：
   L1-49 = 4.17×10⁵、L1-50 = 8.69×10⁵、L1-51 = **5.59×10³**、L1-55 = 1.35×10⁵、L1-56 = 4.79×10⁵、L1-60 = **1.86×10⁶**。
   ⇒ **二批不存在「跨试件可比 **且** 随寿命显著演化」的量**。
   **这是通道 / 物理层面的限制**（仅 AE + 分布式应变，且 AE 阈值/增益跨 campaign 不同），**不是方法论或实现问题**。
2. ❌ **不能把「看起来很像我原因」的三件事当原因**（已逐一排除）：

   - **工况不一致？** ❌ 一致 —— −6.5/−65 kN、2 Hz、10 J，**无分段加载**。
   - **17.2× 寿命跨度？** ⚠️ 只是部分 —— 主因是**冲击位置分组不当 + 设备异常**；干净分组仅 2.05× / 1.33×。
   - **数据质量差？** ❌ **不是主因** —— 有真实缺陷（cycle 计数重置 ×2、机器故障保活 ×1、前期测量缺失 ×2），
     但干净 6 组重算后 `cum_hits` 的 CV 仍 **0.65**。
   - （补）**阈值/实现 bug？** ⚠️ 有，且**恰好说明方案脆弱** —— 只修**一个组**的伪影（覆盖率截断），
     `win10_hits` 阈值就动 **13%**、LOSO 达档中位 **70.4% → 97.9%**（27 个百分点）。
     "阈值一动结论就变"本身就是不可用的核心证据。
3. ❌ **不能做 RUL**。
   相对 RUL（LOSO，MAE/寿命%）在 20% 处 31.5 / 40% 处 11.4 / 60% 处 11.7 / 80% 处 29.5 → **非单调**；
   根因同一条：**缺少组间可比的退化指标**。
4. ❌ **不能报定位"准确性"，也不能报绝对寿命定位过细**。

   - 真值需 NDT 成像，而**无此数据且已定案不追查** ⇒ 「距冲击点」指标**作废**；
     只能把 σ 读作"离散程度"（且是 9 组质心之间的散布，**既非定位误差、也非单组内重复性**）。
   - 无监督异常在 15.5% 报警，而 D 的检测起始在 45.7% —— 两者对"损伤起点"的定义不同。
   - 3 通道 = 2 个独立 TDOA = 2 个未知量，残差**必然趋零** ⇒ **不能把 3 通道结果当定位精度**；
     `ae_locate.py` 默认 `min_ch` 已由 3 改为 **4**。
5. ❌ **不能把 L1-56 读成"损伤最严重"**。
   其基线 AE 活动**异常低**（`ae_rate` 基线 3.4 vs 其他组 35.8/44.3）⇒ 疑似**采集问题**。
6. ❌ **不能把 L1-55 / L1-60 的后段当真**。
   DFOS 覆盖仅 72.2% / 67.5%，后段为**端点外推**（L1-59 AE 仅 62.7%、L1-60 AE 仅 70.8%）。
7. ❌ **交付定位（已定案）**：
   ✅ 可交付 = **离线损伤复评**（`HI_AE`，t85 中位 92.1%）+ **组内趋势提示** + 三项扩展任务（机制 / 一维定位 / 无监督退化量化）；
   ❌ 不可交付 = 跨试件可比、可设统一阈值的**在线预警**。

**C L1 二批（9 组）—— 哪些方法不行**

- **DFOS `local` 做在线预警**：❌ —— 随寿命增长弱（≈15–20%），且路径不可比（早期 190×）。
- **AE × DFOS 融合**：❌ 退化 —— 只做加权平均，**未引入新信息**；融合后仍不可比。
- **严重度分工**（DFOS 严重度 + AE 进度，"各取所长"）：❌ 证伪 —— ρ = **−0.283**（方向相反）；分级一致 **3/9 = 随机**。
- **DFOS 四口径中的 `_peak` / `_amp` / 峰位**：❌ 证伪 —— 见〈A 主样本 —— 哪些方法不行〉（欠采样相位混叠 / ρ 反向）。
- **5 个 RUL 特征族**：❌ —— 单调性 ρ 正负混杂。
- **纯 AE 单源在线预警**：❌ —— 干净子集内活动度仍跨 384 倍；阈值一动结论就变。
- **3 通道定位**：❌ 无意义 —— 残差恒为 0（方程数与未知数相等）。

**C3/C4 新组（14 组 26 卷，AE `.DTA`）—— 指标筛选实测**

- **b 值（Gutenberg-Richter 幅值-频度幂律）**：❌ 淘汰 —— 帧级 Spearman |ρ| 中位仅 **0.09**（14 组里 3 正 2 负 6 弱，方向混杂）。与〈A 主样本 —— 哪些方法不行〉里 b 值 ρ = −0.62 至 0.63 的旧结论**同向** ⇒ 两套独立数据都判它无效。
- **幅值形状类**（幅值熵 / A95−A50 / ≥80 dB 占比 / 幅值分位 / 幅值均值）：❌ 弱 —— |ρ| 仅 0.17 至 0.31，且方向混杂。
- **根因（技术性、可复现）**：该采集把幅值量化成 **1 字节 dB**，且**上限硬饱和在 100 dB**（多数组"帧内最大值的**中位数**"就等于 100）⇒ 分布高位被截断，形状类指标先天缺信息。
- **通道不对称度** |n₁−n₂|/(n₁+n₂)：❌ 淘汰 —— 4 正 5 负，方向混杂（原设想用它代理"损伤偏向"）。
- **帧级活动率**（hit 数/帧）**不能当损伤进度**：⚠️ 14 组里有 4 组（L1-14/25/29/31）随寿命**下降**。机制：提载瞬间活动爆发、随后级内衰减，率由"级内衰减 vs 级间跃升"竞争决定 ⇒ 这正好解释了 Broer 为什么用**累积量**而不是率做 HI。
- **绝对活动度做跨试件阈值**：❌ 再次证伪 —— 帧级 hit 数跨组差 **4 至 5 个数量级**（通道 1 从 3 到 106,649），比老组 C 批"跨 384 倍"更极端。
- **成立的部分**：组内**累积量**口径（累积 hit 数 / 累积能量 / 累积信号强度）。其中**通道 2 的活动度在 12 组里 8 正 0 负（零反例）**，是全部候选里跨组一致性最高的；但只能是**自归一化 + 离线复评**口径，不能做统一阈值在线预警。
- **新组相对老组的结构性优势**：26 卷里 **21 卷采集配置完全相同**（阈值 62 dB / 增益 0 dB / 采样 1 MHz / 时延 −50 µs / 同一套 15 特征）⇒ 跨试件归一化**有基础**。例外 3 处：L1-41 两通道 67 dB、L1-14 与 L1-24 的通道 2 为 60 dB。
- **RA–AF 剪切占比**（按 `ae_raf.py` 口径的帧级近似）：⚠️ 一致性 0.40 / |ρ| 0.34 —— 弱于老组"7/9 成立"，但本次用的是"帧内 RA/AF 中位数"的近似（非逐 hit 二值化）⇒ 口径加强后再评。
- **待验证的方向**：把时间轴映射到**循环轴**（用 FBG 应变量级切分载荷级 + PDF 的每级循环数）⇒ 寿命分数改为真实循环分数，才可能得到"单位循环活动量"这类**跨试件可比**的指标。

**C3/C4 新组 —— 循环轴与指标归一化（实测）**

- **FBG 判「加载 / 停机」有效**：同一窗内 10 个应变通道的峰峰值 —— 加载态 **1500 至 3100 µε**、停机态 **3 至 16 µε**，分离度近 100 倍。
- **FBG 应变幅值分辨不出载荷级**：级间差只有 12 至 15%，而帧间测量波动达 30% ⇒ 不能用它切载荷级，只能用来切「加载/停机」。
- **循环轴自检**：用「加载帧占比 × 日历跨度」反解载荷频率，6 个 FBG 覆盖充分的组落在 **1.86 至 2.18 Hz**（名义 2 Hz），按 2 Hz 预测 n_f 的偏差在 **±8%** 内。不合格的：L1-31 **−26%**（两次加载间隔 23 天拉低占比）、C3 四组 **+74% 至 +105%**（FBG 只覆盖测试期的一小段，占比外推失效）、L1-30/34/36 **+25% 至 +44%**（测试太短，FBG 窗口仅 4 至 54 个）。
- ⚠️ **方法论纠正**：**Spearman 只依赖秩**，而任何单调横轴变换都不改变秩 ⇒ 「换成循环轴后指标排名完全不变」**不是稳健性证据**，是数学必然。要检验横轴选择必须用对缩放敏感的度量（Pearson、t85、绝对值离散度）。
- **循环归一化的实际收益有限**：跨组「每循环 hit 数」的 IQR/中位为 **1.47**，而「每加载小时 hit 数」为 **1.71** —— 只改善 14%；绝对值仍跨 **42 倍**（1.65 至 69.6 次/循环）⇒ **统一阈值的跨试件在线预警仍然不可行**，与老组 C 批结论一致。
- **能量口径不稳定，应当弃用**：`HI_eng`（累积 ABS-ENERGY 自归一化）的 t85 跨 **22.9% 到 96.3%**（73 个百分点），而 `HI_hit` 口径只有 **83.2% 到 100%**（17 个百分点）⇒ 少数大能量事件会拉动整条曲线。
- **成立且可交付的口径**：`HI_hit` = 累积 AE hit 数自归一化 —— t85 中位 **93.1%**，与老组 C 批 **92.1%** / B 批 **92.6%** 一致；**13/13 组尾段单调不回落**。注意这是**离线复评**（归一化用到终值），不是在线预警。
- **通道选择**：通道 2 的活动度在 12 组里 **8 正 0 负（零反例）**，是整个候选项里最强的一致信号；L1-14 与 L1-24 的通道 2 阈值为 60 dB（比通道 1 低 2 dB）⇒ 该通道更灵敏，可能是原因。

**C3/C4 新组 —— 重启响应与载荷级识别（实测，均为否定结论）**

- **重启响应（Kaiser / Felicity 的量化版）**：❌ 无区分度 —— 用 FBG 找停机段（L1-25 **294** 次、L1-41 **315** 次、L1-29 **239** 次、L1-31 225 次），定义 `R = 重启后 30 min 活动 / 停机前 30 min 活动`，实测 **R 中位 1.005 至 1.038**、`ρ(R, 寿命)` 全在 **±0.14** 内。
- 上面的机制很清楚：这批停机是**同载荷级的夜歇**，Kaiser 效应让活动水平原样延续，所以不跃升 —— **提载并不伴随停机**。当初设想“停机就是换级”的推理是错的。
- **载荷级边界无法可靠识别**（三重堵死）：① FBG 应变分辨不出载荷级（级间差 12 至 15%，小于帧间波动 30%）；② AE 活动受“提载爆发 + 级内衰减”混淆；③ 重启点与提载无关。⇒「**载荷级响应对照曲线**」在这批数据上做不了。
- **推论**：凡是以“活动率”为载体的指标（包括单位循环活动量、提载跃升比）都受同一限制 —— 率由“级内衰减 vs 级间跃升”的竞争支配，不是损伤的单调函数。
- **✅ 成立（新挖出的指标）：Fano 簇状性** —— 60 s 帧 hit 数的滑动窗（60 帧 = 1 h）$F=\mathrm{var}(n)/\mathrm{mean}(n)$。实测后 30% 寿命的 F 中位 **668**（范围 22.6 至 2978，全部远大于 1）⇒ 事件**强烈簇状而非常泊松**；`ρ(F, 寿命)` 为 **7 正 0 负 5 弱（零反例）**，|ρ| 中位 0.38。
  · 它的价值在**机理与活动度独立**：看的是涨落结构而非量级，正好绕开“率受级内衰减支配”的坑，可作互补指标。
  · 限制：F 的**绝对值跨组 130 倍**（同样不能做统一阈值），只能当**组内相对量**（变化率）。
- **二维损伤相图（横轴 HI、纵轴 Fano）**：⚠️ 部分成立 —— **9/12 组**的末期 Fano 高于 20% 寿命处（与 Fano 单指标结论一致）；但**对损伤类型的可分性未能证实**：两个预置脱粘组的末期 Fano 一个极低（L1-41 = **19.1**，全场最低档）一个很高（L1-44 = **998.7**），而两者载荷剖面本就不同（L1-41 全程轻载、L1-44 先重载后转轻载）⇒ n = 2 且工况混淆，**不能声称"相图对损伤类型敏感"**，只能当组内可视化与诊断用。
- L1-41 的 Fano 全场最低（20 至 64）是唯一的"类型线索"：它已预制 D20x20 脱粘，开测前损伤就存在，加载期损伤缓慢稳定扩展 ⇒ 事件稀疏均匀。但**单例不能定论**。

**C3/C4 新组 —— 跨模态独立验证（✅ 成功，本轮最有力的正面结论）**

- **做法**：FBG 的 10 个应变通道（R1 至 R5 在 A 侧、L1 至 L5 在 B 侧）在每个加载窗内**按窗归一化**成分布向量（消掉载荷级的整体缩放），再与**首窗**算 L1 形状距离 `shape_l1`。
- **结果**：`ρ(shape_l1, 窗序)` 为 **正 7 / 负 1 / 弱 5（13 组）**，**|ρ| 中位 0.59** —— 是本次全部候选指标里 |ρ| 中位**最高**的一个。亮点：L1-35 **+0.940**、L1-06 +0.863、L1-25 +0.844、L1-24 +0.698、L1-41 +0.689、L1-44 +0.688、L1-29 +0.589。
- **关键优势：在线可用** —— `shape_l1` 只需要**首窗基线**（属过去数据），不需要终值 ⇒ 与 `HI_hit`（需终值归一化、属离线复评）不同，这是第一个"在线可用且 |ρ| 高"的指标。
- **物理依据**：脱粘／分层扩展改变载荷路径 ⇒ 应变剖面形状漂移，这正是老组 B 批用 DFOS 验证过的同一物理量。
- **跨模态互相印证**：FBG（应变场）与 AE（事件流）两个**独立模态**都显示损伤单调演化，方向一致 ⇒ 相当于新组版的"AE × DFOS 交叉验证"（老组 C 批曾得 8/9 正相关，但那批有 DFOS；新组没有，这是 FBG 版本的复现）。
- 限制：`shape_l1` 的绝对值跨组 0.165 至 1.458（9 倍）⇒ 仍不能做跨试件绝对阈值，只比 AE 活动量的 42 倍好得多。

### C3/C4 新组 —— TDOA 一维方位（⚠️ 技术成立，指标不强；区分于主样本的「完全不可做」）

⚠️ **先纠正一个容易混淆的点**：前文"不能做 TDOA 定位"指的是**主样本（main）** —— 那批 AE 没有到达时间（时间轴由 `np.linspace` 均匀生成）且只有单通道，属**物理上不可能**。**C3/C4 新组不同**：`.DTA` 带 RTOT（0.25 µs 分辨率触发时刻）且**每试件 2 通道** ⇒ TDOA 在原理上可算。本节讲的是"能算但算出来好不好用"。

**1）配对技术成立（✅ 这一部分是干净的）**

- 做法：同帧内按触发时刻就近配对两个通道的 hit，取 `dt = t₂ − t₁`。
- L1-29 实测：`|dt| ≤ 5 / 10 / 20 / 50 µs` 的配对占比 **23.0 / 47.1 / 54.0 / 74.8%**。该组事件率约 4 事件/s，两个**随机**事件落在 ±10 µs 内的概率约 **0.008%** ⇒ 配对不是偶然。
- 配对后两通道**幅值相关系数 +0.889 至 +0.923**（打乱时间轴后对照 ≈ 0）⇒ 配对到的是**同一个物理事件**，不是噪声拼接。
- ⇒ **"两通道能配对、能算时差"这件事本身无争议**。

**2）帧级 `dt_med` 作指标偏弱（❌ 作为损伤指标不成立）**

- `ρ(dt_med, 寿命)` = **正 2 / 负 1 / 弱 8**，**|ρ| 中位 0.23** —— 落在已被淘汰的"幅值形状类"同一档（0.17 至 0.31）。
- 与主指标对比：FBG `shape_l1` 的 |ρ| 中位 0.59、通道 2 活动度 0.54 ⇒ **`dt_med` 明显更低**。
- **原因**：`dt_med` 是**整帧所有配对事件的中位时差**，而一帧内事件来自**整个试件**（多点源）。局部脱粘前沿移动引起的方位变化，被全场源的平均稀释掉了 ⇒ 这不是"数据不行"，是**口径层级不对**（帧级平均 vs 源级定位）。

**3）高幅值分档：|ρ| 中位确实上升，但符号开始翻转（⚠️ 半路收益，仍不可用）**

只用高幅值事件（大事件更可能来自主损伤源，可聚焦"主声源方位"）：

| 口径 | 正 / 负 / 弱 | \|ρ\| 中位 |
| --- | --- | --- |
| 全部配对 `dt_med` | 2 / 1 / 8 | 0.23 |
| `dt_med_p75`（≥75 dB） | 3 / 2 / 6 | 0.26 |
| `dt_med_p85`（≥85 dB） | 4 / 3 / 4 | **0.43** |

- |ρ| 中位 **0.23 → 0.26 → 0.43** 确有抬升 ⇒ **"聚焦大事件"的方向是对的**。
- 但**符号不一致了**：`p85` 口径下 L1-25 **−0.430**、L1-24 **−0.626**、L1-41 **−0.647** 由弱转强负。
  ⇒ 各试件的主声源**不在同一方位**，甚至**向相反方向迁移**；无统一符号就不能当跨试件指标。
- 只有 **L1-29（+0.479 / +0.536 / +0.425）与 L1-44（+0.730 / +0.456 / +0.527）在两档阈值下都稳定为正** —— 这两组是**长测试、大循环数**（配对中位 706 / 730），说明 `dt_med` 只在"损伤充分发展 + 事件足够多"时才显形。

**4）口径限制（必须写进交付说明）**

- `dt_med` 绝对值跨组 **−15.25 至 +10.50 µs** ⇒ **只能做组内相对量**，跨试件不可比。
- 要输出**绝对毫米坐标**，必须知道 **AE 传感器坐标 + 声速**；PDF 只给了 **FBG 通道布置**，AE 探头位置未给 ⇒ **当前数据不足以做绝对定位**，需向数据方索取。

**5）结论**

- TDOA **不是**"能不能做"的问题，而是"**帧级时差这个口径太粗**"。
- 若后续要做，正确的下一步是**源级定位**（对每个配对事件算方位角，做方位角分布/主方位的时程），而不是帧内取中位 —— 但那需要先解决传感器坐标缺失。
- 本轮**不交付 TDOA 指标**；交付的是「配对可行性已证 + 帧级口径偏弱 + 绝对定位缺输入」这三条边界。

#### 1b）真问题：AE 帧与 FBG 突发的网格不匹配，导致循环轴大面积「补值」

`ae_cycle._ratio_on_grid()` 要求每个 600 s 的 AE 帧在 ±300 s 内凑到 **>= 3 个 FBG 窗**才采信，否则把该帧的加载占比用**全局均值**补齐：

```python
if m.sum() >= 3:  g[i] = lf[m].mean()
g[np.isnan(g)] = float(lf.mean())          # 其余帧全部赋全局均值
```

但突发式采集每 420 s 只给 **2 个** FBG 窗（140 行 + 剩余行），600 s 窗口平均只能罩到约 1.4 个文件 ≈ 2.9 个窗 ⇒ **>= 3 这个阀值太紧**。实测后果：

- `g_load` 退化成只有 **2 至 15 个离散取值**，单一众数占 **50% 至 73% 的帧**，且多文件组的众数正好落在分数上（0.474 / 0.646 / 0.655 / 0.727 / 0.799 / 0.870）—— **就是补值**；
- 这些区段的循环轴因此变成近似**线性时间斜坡**（`g` 为常数）。

⇒ 这是一个**真实存在的口径缺陷**（需修 `ae_cycle`；建议改用「最近一次突发的加载状态外推」，而非全局均值），但性质是「网格不匹配 + 均值补值」，**不是读取丢数据**。诊断工具：`l1/fbg_coverage.py`。

#### 1c）但「频率自检失真来自补值」这个推断**不成立**（已实测否证）

#### 2）（B）L1-31 反常的根因 —— 不是窗异常，而是「基线选错 + 早期状态迁移」

#### 10）L1-14 查因：不是「无信号」，而是「被窗质量噪声淹没」（2026-10-04）
