## 4. 对现稿的四点启示

1. **表少图多。** 表数中位 **0**（范围 0 至 2），图数中位 5。你的稿子有 Table 1 与 Table 2 两张表、五张图。两张表不算过分，但要把表当"图讲不完时才用"，主体证据走图。
2. **参考文献 13 条正好是这条线。** 中位 13，范围 0 至 31，与现稿的 13 条完全吻合，无须增补。
3. **限制段几乎没人写。** 39 篇里只有 2 篇设了独立小节。你原来把 Discussion 删掉、结论里并入两句限制，这个取向与会体裁一致，不必恢复 Discussion。
4. **公开数据集在这个会是少数派。** 39 篇里只有 2 篇涉及可共享数据，绝大多数论文是自建试验台。这既是风险也是机会：用公开数据会被问"为什么不自己测"，但反过来，跨机构可比性这类主张又只有公开多机构数据才能支撑，所以引言里必须主动交代这个取舍。
