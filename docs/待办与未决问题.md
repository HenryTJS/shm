## 1. 交付时必须声明的限制

| 限制                         | 说明                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| `HI_hit` 是**离线**口径      | 需全寿命终值归一化（`unity01`），不声称在线                                                |
| `shape_rob25` 有**暖机期**   | 基线取自前 25% 加载窗，前 25% 寿命内不可用                                                 |
| **绝不跨试件统一阈值**       | `shape_l1` 绝对值跨组 9 倍、AE 活动量跨 42 倍；只做组内自归一化                            |
| 新组**无 DFOS / PZT**        | 依赖 DFOS 的证据口径不可用                                                                 |
| FBG**时间覆盖粗**            | 有效观测仅 5.7 至 17.2 h，占空比约 5%                                                      |
| **FBG 覆盖率跨组差很大**     | 批次 A（C3）为 **13 % 至 17 %**，C4 为 **3 % 至 8 %**；且缺失部分是**大量中等间隙**而非大洞（§26） |
| **FBG 窗距跨组差 29 倍**     | 实测窗距中位：C3 四组均 28.0 s；C4 里 L1-25/27/29/31/41 是 406 s、L1-35 是 226 s、L1-30 是 88.4 s、**L1-44 只有 14.0 s**（其实是长记录型）⇒ **不能按 campaign 推断记录格式**（§25）。⚠️ 它只统计**加载窗之间**的间隔，**看不见停机**，所以不能用它解释 `gp`（§27） |
| **`gp` 不是工况占空比** | `gp`（FBG 窗级加载占比）跨 C4 组从 0.474 到 0.870，差异由**试验执行**决定：机器正常跑的日子各组都是 **0.82 至 0.88**，低的组只是**整天级停摆的天数多**（L1-31 有 7 天、L1-41 有 0 天）。AE 已独立证实（§27） |
| **`rho(g,AE)` 不是全组可用** | 有两种退化机理：(a) **无停机段的组上无定义** —— L1-14 的 `g` 恒为 1 ⇒ NaN，L1-06（99.0 % 为 1）/ L1-13（99.7 %）退化成噪声（§26 已证实这些组确实没停机段，**不是数据问题**）；(b) **AE 帧级事件数贴近本底** ⇒ L1-41 给 −0.027（§18 更正 3）。引用时**必须报可用组数与中位**（生产口径：8 组、中位 0.494），不得引用含退化组的均值 0.35（§28） |
| **`rho(g,AE)` 是帧级口径，会低估关联** | 一个 600 s 帧含 43 个 FBG 窗，只要一部分在跑就仍有事件 ⇒ 旧「加载帧事件多」被稀释。日尺度对照是 **Spearman 0.886**。⇒ 它只能当**粗筛**，不能当「加载重建正确性」的证据（§27 / §28） |
| **主曲线固定为 `HI_hit`** | 通道 2 在**逐帧秩相关**口径最强（\|rho\| 0.54 对 0.30），但在**累积 t85** 口径最分散（极差 **22.2** 对 16.7），通道 1 反而是 14.9。⇒ 选型规则：**先定交付形态（逐帧还是累积）再选指标**，两种判据不可互推（§7 / §30） |
| **不声称 Fano 对损伤类型敏感** | 预置脱粘只有 2 组（L1-41 / L1-44），两者后 30 % 的 Fano **相差 43 倍且一高一低**（22.6 对 972.9），而两者载荷剖面本就不同；低 Fano 档里还有**没有**预置脱粘的 L1-25 / L1-29 ⇒ n = 2 + 工况混淆 + 对照不特异。Fano 只按**组内涨落结构指标**交付（§31） |
| **`rho` 不能按 n 声称显著性** | 剖面序列强自相关（acf1 中位 A 0.663、B 0.957），AR(1) 的 n_eff 在 5/8 个 C4 组上退化。需报告显著性时用 `--batch` 的循环分块置换 `p_block`（保留自相关）|
| **C3 批的 f = n_f / 日历跨度** | 批次 A 的 `g<0.3` 帧占比 0 %、g 均值 0.996 ⇒ `load_h ≈ span_h`，频率完全由日历跨度决定 ⇒「C3 四组 f 落在 1.075 至 1.148」**不是载荷重建正确性的独立证据**（对 C4 才是，那里的守卫削掉 12 % 至 23 %）。见 §26 |
| **`load_h` 不是日历占空比**  | `load_h = sum(g) x 600 s`，求和只跑在**稀疏的 AE 帧网格**上（只为有事件的时段建帧）⇒ 它是「**AE 在录时段内**的加载时长」。定义与实测见 `details.md` §19 |
| **`shape_rob25` 的 rho 依赖基线窗数量** | 改样本量就会改 rho（子集重算基线时 12 组 \|Δrho\| 中位 0.054、最大 0.208）。评估过滤效果必须**固定基线 + 原寿命序**；生产的两条排名线本来就是这么做的（§22 / §23） |
| 载荷频率是**反解值**         | 不是实测，PDF 未给（PDF 只给载荷级与循环数）                                               |
| **不交付 TDOA 指标**         | 配对可行（幅值相关 +0.89 至 +0.92），但帧级口径偏弱；且 13 组里只有 5 组四探头正常，不可用的组算出的方位无意义 |
| **不交付绝对定位**           | 原因分三批：**C3/C4** 无 AE 几何（平面图那 10 个位置是 FBG 阵列）；**C1** 声速自述失效；**C2** 唯一可量的残余系统误差约 **35 mm**（L1-54）且受「源随寿命迁移」主导（总迁移中位 139 mm）⇒ 只做相对方位 / 到序 |
| **质心到图纸点的距离不是精度指标** | 全寿命质心是「在整块板上移动的云」的平均；两个「最准」的组恰恰是迁移最大的（§21） |
| **窗质量控制 A 只能用在因果形式** | 现门槛用全寿命中位（非因果）；改成 expanding 中位后除 L1-14 外 rho 基本不变（中位 \|Δ\| 0.006），**但对 L1-14 的「提升」会消失**（§22） |
| **L1-41 的帧级事件数不能当加载判据** | 它的事件数贴近本底（加载帧 862.5 对 停机帧 956，比值 1.108，`details.md` §18 更正 3）；但其 `HI_hit` 等指标正常，**照常交付**，不得写成「该组不可用」 |
| **交付物里不放机器相关的列** | `AE特征概览.csv` 原有的「解析耗时s」会让产物不可复现，已移除（§24）。新增交付列前先想一遍：它会随环境变吗 |
| 不声称「约束层四套通用」     | 该层对无状态逐点回归有效，对累积型指标收益为 0                                             |

## 2. 明确不做（已定案，不要重开）

### 2.1 已被实测否证的方向

- **改 `P2P_LOAD`、给 AE 守卫加幅值条件、给 L1-41 降级、按应变水平改口径、
  按 A/B 改交付口径、换排名统计量、给 `ae_loadstep` 加停机检测** —— 七条都已被实测否证
  （`details.md` §15 ①、§17 ③、§18 更正 2 / 3 / 4、§22、§23、§26）。
- **用 A / B 去「救」L1-14** —— §22 已查明两条路的效果都是假象。它就是信噪比不足。
- **为 L1-31 的 `gp` 找「采样相位偏置」的解释** —— §27 已定案：真实工况差异，
  且「L1-31 是离群值」这句本身要撤回（C4 的 `gp` 是一条连续谱）。
- **改 `rho(g,AE)` 的口径、或把它当「加载重建正确性」的证据** —— §28 已定边界；
  要下结论用 §27 的逐日对照。
- **再把 `aeact` 拉回来当生产口径** —— §29：它的 rho 并不差，但缺 `MAX_CARRY` 截断、
  会把停机时段多标「加载」，且使 L1-24 的 `g` 退化成常数。
- **继续挖定位** —— §21：迁移主导，13 组里只有 1 个干净样本，投入产出比低。

### 2.2 样本量不足 / 没有检验力

- **Fano 对损伤类型的敏感性** —— 预置脱粘 n = 2，两个样本结论相反（后 30 % 的 Fano
  22.6 对 972.9）且工况混淆；低 Fano 档里还有无脱粘的组 ⇒ 在补齐样本前不可检验（§31）。
- **相图（HI × Fano）之外的二维组合搜索** —— 唯一有先验机理的组合已测且未获证实；
  其余属事后穷举，任意组合都能凑出「看起来可分」的切分，得到的发现不可证伪（§31）。

### 2.3 明确不追查

- RUL 真值、仿真、NDT 真值的追查。
- 向数据方索取补充数据（公开数据集无此渠道，已确认）。
