## F. 已更正事项（避免重复提出）

以下三处曾得出错误结论，已实测否证，留档以免重犯：

| 曾经的错误说法                                        | 实际结论                                                                                                                                                                            |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scan_fbg` / `_scan_windows` 的 `i < 60` 丢数据 | **错**。表头 37 行 + 标定式 + 列名行，数据确实从第 60 行起，**原实现正确**。教训：「字段数 ≥ 12」不能当数据判据（标定式有 17 列）                                      |
| L1-25 / L1-31 的 FBG 覆盖率仅 39%                     | **错**。分母用了整段日历时间，把试验暂停算成缺数据。活跃期覆盖率 **98.6% 至 100.1%**                                                                                    |
| L1-31 的频率自检 −26% 是「补值假象」                 | **错**。用 FBG 实测时长反解会得到 19 至 21 Hz（荒谬），证明 FBG 只观测到加载时长的约 **10%** ⇒ `load_h` 必然是外推值，该自检**本身不可靠**，不能当数据异常证据 |
| 「完全不能做 TDOA」                                   | **需区分**：main 主样本不可做（无到达时间、单通道）；L1 新组可做，但帧级口径偏弱                                                                                              |
| 「通道 2 是最强 AE 指标」                             | **说窄了**：只在**逐帧活动度**口径下成立；换成**累积 t85** 口径则最分散（极差 22.2 vs 全部 hit 16.7）。两个判据回答不同问题                                       |
| 「PDF 只给了 FBG 通道布置，AE 探头位置缺失」           | **错**。E 盘根 4 份位置 PDF 每页都有试件平面图，标注了 `AE sensors` 的 10 个位置 `L5R5…L1R1` 与 `PZT`，带 `X(mm) / Y(mm)` 坐标轴；且前三份是**纯矢量**，传感器标签带精确坐标 ⇒ **几何可提取**。教训：**「数据里没有」要先穷尽自带文档再下结论** |
