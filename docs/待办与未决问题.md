## 1. 交付时必须声明的限制

| 限制                                            | 说明                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `HI_hit` 是**离线**口径                 | 需全寿命终值归一化（`unity01`），不声称在线                                                                                                                                                                                                                                                                                                                                  |
| `shape_rob25` 有**暖机期**              | 基线取自前 25% 加载窗，前 25% 寿命内不可用                                                                                                                                                                                                                                                                                                                                     |
| **绝不跨试件统一阈值**                    | `shape_l1` 绝对值跨组 9 倍、AE 活动量跨 42 倍；只做组内自归一化                                                                                                                                                                                                                                                                                                              |
| **DFOS 只有 C1/C2 有；PZT 全都没有**      | 实测（递归搜`E:\l1`）：DFOS（ODiSi / LUNA）只在 **C1**（L1-03/04/05/09）与 **C2**（L1-49 至 L1-60）存在；**PZT 一个组都没有**。旧表述「新组无 DFOS / PZT」会让人以为老组有 PZT，已更正（§32 / `shm/datasets.py`）⇒ 依赖 DFOS 的证据口径对 C3/C4 不可用；依赖 PZT 的口径对**全部**组不可用                                                        |
| FBG**时间覆盖粗**                         | 有效观测仅 5.7 至 17.2 h，占空比约 5%                                                                                                                                                                                                                                                                                                                                          |
| **FBG 覆盖率跨组差很大**                  | 批次 A（C3）为**13 % 至 17 %**，C4 为 **3 % 至 8 %**；且缺失部分是**大量中等间隙**而非大洞（§26）                                                                                                                                                                                                                                                           |
| **FBG 窗距跨组差 29 倍**                  | 实测窗距中位：C3 四组均 28.0 s；C4 里 L1-25/27/29/31/41 是 406 s、L1-35 是 226 s、L1-30 是 88.4 s、**L1-44 只有 14.0 s**（其实是长记录型）⇒ **不能按 campaign 推断记录格式**（§25）。⚠️ 它只统计**加载窗之间**的间隔，**看不见停机**，所以不能用它解释 `gp`（§27）                                                                              |
| **`gp` 不是工况占空比**                 | `gp`（FBG 窗级加载占比）跨 C4 组从 0.474 到 0.870，差异由**试验执行**决定：机器正常跑的日子各组都是 **0.82 至 0.88**，低的组只是**整天级停摆的天数多**（L1-31 有 7 天、L1-41 有 0 天）。AE 已独立证实（§27）                                                                                                                                              |
| **`rho(g,AE)` 不是全组可用**            | 有两种退化机理：(a)**无停机段的组上无定义** —— L1-14 的 `g` 恒为 1 ⇒ NaN，L1-06（99.0 % 为 1）/ L1-13（99.7 %）退化成噪声（§26 已证实这些组确实没停机段，**不是数据问题**）；(b) **AE 帧级事件数贴近本底** ⇒ L1-41 给 −0.027（§18 更正 3）。引用时**必须报可用组数与中位**（生产口径：8 组、中位 0.494），不得引用含退化组的均值 0.35（§28） |
| **`rho(g,AE)` 是帧级口径，会低估关联**  | 一个 600 s 帧含 43 个 FBG 窗，只要一部分在跑就仍有事件 ⇒ 旧「加载帧事件多」被稀释。日尺度对照是**Spearman 0.886**。⇒ 它只能当**粗筛**，不能当「加载重建正确性」的证据（§27 / §28）                                                                                                                                                                             |

## 2. 明确不做（已定案，不要重开）

### 2.1 已被实测否证的方向

- **改 `P2P_LOAD`、给 AE 守卫加幅值条件、给 L1-41 降级、按应变水平改口径、
  按 A/B 改交付口径、换排名统计量、给 `ae_loadstep` 加停机检测** —— 七条都已被实测否证
  （`details.md` §15 ①、§17 ③、§18 更正 2 / 3 / 4、§22、§23、§26）。
- **用 A / B 去「救」L1-14** —— §22 已查明两条路的效果都是假象。它就是信噪比不足。
- **为 L1-31 的 `gp` 找「采样相位偏置」的解释** —— §27 已定案：真实工况差异，
  且「L1-31 是离群值」这句本身要撤回（C4 的 `gp` 是一条连续谱）。
- **改 `rho(g,AE)` 的口径、或把它当「加载重建正确性」的证据** —— §28 已定边界；
  要下结论用 §27 的逐日对照。
- **再把 `aeact` 拉回来当生产口径** —— §29：它的 rho 并不差，但缺 `MAX_CARRY` 截断、
  会把停机时段多标「加载」，且使 L1-24 的 `g` 退化成常数。
- **继续挖定位** —— §21：迁移主导，13 组里只有 1 个干净样本，投入产出比低。

### 2.2 样本量不足 / 没有检验力

- **Fano 对损伤类型的敏感性** —— 预置脱粘 n = 2，两个样本结论相反（后 30 % 的 Fano
  22.6 对 972.9）且工况混淆；低 Fano 档里还有无脱粘的组 ⇒ 在补齐样本前不可检验（§31）。
- **相图（HI × Fano）之外的二维组合搜索** —— 唯一有先验机理的组合已测且未获证实；
  其余属事后穷举，任意组合都能凑出「看起来可分」的切分，得到的发现不可证伪（§31）。

### 2.3 明确不追查

- RUL 真值、仿真、NDT 真值的追查。
- 向数据方索取补充数据（公开数据集无此渠道，已确认）。
