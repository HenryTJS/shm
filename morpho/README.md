# morpho：MORPHO FOD7（发动机风扇叶片前缘 FOD 板）

H2020 **MORPHO** 项目公开的实验数据集：一块**发动机风扇叶片前缘的替身结构**（FOD panel），
用来做有真实损伤演化的 SHM 基准。它补的是另外三个平台缺的一块 ——
**几何复杂（曲面 + 变厚度）+ 多模态同步 + 一直到破坏的完整疲劳史**。

原始数据不在仓库里：`morpho/data/` 是指向 `E:\morpho` 的**目录联接**，只有 3 个文件
（`MORPHO_FOD7.h5` 7.96 GB、`ReadMe.pdf`、`EXAMPLE_READ_DATA.m`）。

> 本文件夹的第一性产物是**解包后的 CSV**（写在 `E:\morpho\processed\`，共约 120 MB）。
> 那就是「初步处理」的交付物：每个模态一个目录、宽表优先、配一张 summary。

## 1. 结构与试验

| 项 | 内容 |
| --- | --- |
| 试件 | FOD7 板：3D 编织碳纤维复材，长约 800 mm、宽约 350 mm，**曲面**且厚度沿宽度变化（前缘含钢边 6.3 mm → 中段 10.8 mm → 后缘 2.8 mm） |
| 加载 | 四点弯曲，**压-压**多级疲劳（4 → 24 kN，每级固定圈数），载荷逐级加大直至破坏 |
| 损伤引入 | 先做落锤冲击（球头 5 kg / φ10 mm，约 55 J），得到目视勉强可见的损伤 |
| 传感 | 4 个**标准陶瓷 PZT**（编号 1–4，唯一可作动）+ 25 个**丝网印刷 PZT**（5–29）+ 2 根光纤共 **16 个 FBG** |
| 模态 | 电化学阻抗、FBG 应变、冲击响应、试验机载荷-位移、主动导波（Lamb 波） |

HDF5 内部五个顶层组，`MORPHO_FOD7.h5` 一个文件装全部：

| 组 | 内容 | 规模 |
| --- | --- | --- |
| `1_Impedance` | `FOD7_Healthy` / `FOD7_Failed` × PZT_5…29 → `Z` / `phase` / `freq` | 2 × 25 × 801 点（100 Hz–200 kHz，1 V） |
| `2_FBG` | 21 个载荷工况 × FBG_1…16 → `FBG_data` / `time` | 336 组时序，约 2 Hz |
| `3_Impact` | PZT_1…29 → `PZT_data` | 29 × 10⁷ 点 @ 1 MHz（10 s） |
| `4_MTS` | 21 个载荷工况 → `displacement` / `load` / `time` | 21 组，0.5 s 采样 |
| `5_Active` | 25 个损伤工况 × 8 个频率 × 4 个作动器 × 10 次重复 | 8000 条，每条 30 × 5001 @ 1 MHz |

工况：疲劳 21 级 = 4/8/12/14/16/18/20/22/24 kN × 若干循环；另有 4 个基线状态
（`Healthy_Clamped` / `Healthy_Unclamped` / `AfterImpact_Clamped` / `AfterImpact_Unclamped`，
只有主动导波）。

## 2. 怎么跑

```bat
cd morpho
python run.py --list                              rem 任务矩阵（10 个）
python run.py --task check                        rem 只打印 HDF5 结构，不落盘
python run.py --task prepare                      rem 全部解包（约 4 分钟，读满 7.8 GB）
python run.py --task index impedance fbg mts      rem 只做快的四类（约 10 s）
python run.py --task active --limit-active 2      rem 冒烟：每作动器只取 2 次重复

python run.py --task wave50 analyze               rem 第二份数据（5 板 50 kHz）→ CSV → 分析
python run.py --task reproduce                    rem 复现官方论文的刚度 / FBG-HI / 导波三项
```

`--task all` = `prepare → reproduce → wave50 → analyze`。产物默认写 `E:\morpho\processed\`；
`prepare.py --out <目录>` / `prepare50k.py --out <目录>` 可改。

## 4. 读这批数据必须先知道的六件事

1. **载荷单位是 N，不是 ReadMe 写的 kN。** `4kN_200` 的 `load` 峰约 3900、谷约 −4008
   ⇒ 存的是 N。CSV 里同时给了 `load_N` 与 `load_kN`，别重复换算。
2. **载荷全是负值（压）**，`disp_mm` 也是负的；这是四点弯曲压-压疲劳。
3. **工况名里的 N 是累计循环数，不是该级圈数。** 每级各跑固定圈数（≤18 kN 每级 200 圈，
   ≥20 kN 每级 100 圈），所以 `20kN_100/200/300/400` 各录到 100 圈是对的。
   `mts_summary.csv` 里给了 `本次实测循环数` 与 `本次循环数_推定` 两列对照。
   实测少于计划值的只有两处：`12kN_400`（166）与 `24kN_100`（78，试件在该级破坏）。
4. **冲击数据只有 8 个独立通道。** PZT_9…29 是 PZT_1…8 的逐点复制（md5 完全一致）。
   做冲击定位或能量标定时只能当 8 通道用，否则会把同一份信号数 4 遍。
5. **FBG 是 ~2 Hz 断续采集，单条记录常横跨数小时且有大量停机段。**
   例如 `14kN_400` 的 FBG 记录长 54733 s，而对应 MTS 只有 8785 s（6.2 倍）。
   直接取全记录均值会严重偏低（该工况 16 路中位 90，而真实加载段是 971）。
   `fbg_summary.csv` 因此同时给「全记录」与「加载段」（用同工况 MTS 载荷 ≥50% 峰值掩码）两套统计，
   **比较不同工况请用加载段那一列**。
6. **阻抗不要拿 \|Z\| 的最大值当谐振峰。** \|Z\| 在低频被容性主导（100 Hz 处 0.6–0.9 MΩ，
   到 100 kHz 已降到 0.8–1.3 kΩ），最大值必然落在最低频。惯用口径是实部 Re(Z) = \|Z\|·cos φ，
   `imp_delta.csv` 的谐振峰就是在 Re(Z) 上找的局部极大。

## 5. 已经看出来的东西（初步，供下一步用）

- **载荷-应变自洽**：16 路 FBG 的「加载段均值」中位随载荷级单调上升
  ——4 kN **198**、8 kN **460**、12 kN **777**、14 kN **989**、16 kN **1211**、18 kN **1491**、
  20 kN **1857～1904**、22 kN **2413～2611**、24 kN **3258** µm/m。
  同一载荷级内的后一段通常略低（如 12 kN：777 → 707），属疲劳过程中的刚度变化。
  这条单调性同时说明「用 MTS 挑加载段」的掩码是对的。
- **结构刚度退化**：`mts_summary.csv` 的割线刚度从 12 kN 的 **678 N/mm** 单调降到
  24 kN 的 **378 N/mm**。注意 4 kN 只有 644 N/mm —— 低载段被夹具柔度主导，
  **不要**把 4→12 kN 的"上升"当成结构变硬；能用的退化轴从 12 kN 起。
- **阻抗整体几乎没变，只有一个传感器塌了**：25 个印刷 PZT 的 Re(Z) 在 1–100 kHz
  与失效前的相关系数普遍 **≥0.998**（形态基本不变），但 **PZT_23 掉到 0.30**，
  Re(Z) RMS 比 0.29 —— 典型的脱粘/失效，不是结构的整体变化。
- **主动导波幅值随载荷抬升后回落**：以 Actionneur2 激励、PZT_4 接收、100 kHz 为例，
  峰值中位从 4 kN 的 0.26 V 升到 20 kN 的 0.73 V，22 kN 后回落到 0.55–0.68 V。
- **重复性**：同一 (工况, 频率, 作动器, 通道) 的 10 次重复，峰值变异系数中位 **0.14**
  （90 分位 0.24）。单次测量不能分辨小于约 14% 的幅值差异，做损伤指标前要先做 10 次平均。

### 7.1 结论：这个指标是「加载程序进度计」，不是损伤计

主指标 `xcorr_基线` = 当前波形与该通道 cycle0 波形的归一化互相关峰。四块好板都从 1.00
单调衰减到 0.46–0.54（ρ = −0.61 ~ −0.96），看起来像漂亮的损伤演化曲线。**但它是载荷级的假象。**

| 检验 | 结果 |
| --- | --- |
| 单调性 | FOD4 ρ=−0.95、FOD6 ρ=−0.96、FOD5 ρ=−0.71、FOD7 ρ=−0.51 |
| 级内斜率（载荷固定，只涨循环） | 4 板合并 **−0.0014/百循环，p=0.83** |
| 在「载荷级」之上再加「累计循环」 | R² 只涨 **0.000** |
| 载荷级单独解释 | R² = 0.30 |

原因是加载谱：载荷级随循环单调上升，两者在时间上完全共线。每个载荷级内有 2–4 个循环
（如 20 kN 有 2500/2600/2700/2800），**级内载荷不变**，这才是可归因于损伤的窗口 —— 而它没有信号。
所以那个"漂亮的衰减"其实是「载荷从 4 kN 加到 24 kN」改变的波传播条件。

这与主样本里 AE 累积能量是「时钟不是损伤计」是同一类陷阱，见 [`main/README.md`](../main/README.md) §4。

### 7.2 但「能预测寿命分数」是真的，只是别当损伤能力

| 项 | 结果 |
| --- | --- |
| 四板曲线一致性 | 两两 Spearman 中位 **+0.706** |
| 合并四板：`xcorr` vs 寿命分数 | Spearman **−0.502**（p=1e−65） |
| LOSO（二次映射） | MAE **21.8 点**（恒猜 50% 是 28.6 点） |
| 同板内拟合上界 | MAE **21.1 点** |

上界 ≈ LOSO ⇒ 瓶颈在**指标分辨力**，不在迁移性；21.8 点的精度不足以当寿命预测器。
它之所以"能预测"，是因为载荷级 → 寿命分数这条对应关系由加载谱给定，模型学的是加载程序，不是损伤。

### 7.3 数据集本身的两处质量问题

1. **逐次重复里有大量近零幅值的坏信号。** 全库 662 / 12 504 条（5.3%）的 RMS 低于同组最大值的 20%，
   按板剔除率 FOD3 **29%**、FOD4 6.6%、FOD7 3.4%、FOD5 1.6%、FOD6 0%。
   `prepare50k.py` 已按此规则过滤（`_good_reps`），并导出 `reps_dropped.csv`。
   **这条规则被官方的人工标签反向验证**：被剔除的重复里有 44/87 条是人工标注的 BAD（51%），
   而保留的只有 92/924（10%）—— 富集 5 倍。
2. **FOD3 整体不可用**：除上面 29% 的坏重复外，保留下来的信号里仍有 **65%** 被人工标为 BAD
   （其他板 0–6%），且 `xcorr_基线` 与循环无关（ρ=−0.05，p=0.83）。FOD3 已排除在跨试件比较之外。

> ⚠️ 不要用官方 README 的「Cycles」列做分析：那一列等于 `信号数 ÷ 120`（假定每组 10 次重复、
> cycle0 也是 10 次）。实际不同组的重复次数是 4/8/10/30/80，所以该列对 FOD3 偏小、对 FOD4–FOD6 偏大。
> **真实的不同循环档数**：FOD3 **22**、FOD4 **19**、FOD5 **22**、FOD6 **21**、FOD7 **22**。
> 信号数（1104/3120/2880/2760/2640）是对的。

## 8. 边界

- 这是**一个试件的一条加载史**（FOD7 一块板），没有跨试件重复，不能做泛化性结论。
- 冲击是单次事件、4 个传感器作动、8 个有效响应通道，**不足以做冲击定位**。
- 主动导波**不给绝对走时**：接收通道会拾取驱动信号的电串扰，记录开头 0–50 µs 的能量与
  真实到达波同量级，阈值法"到时"没有物理意义。要做得用同通道跨工况差分/互相关（二次分析）。
- 阻抗只有健康与失效两个状态，没有中间态，因此**不能**单独用来做退化曲线。
- 本文件夹只做结构化解包，**未做**任何损伤指标、成像或预后；那些属于下一步。
