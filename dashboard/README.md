### 在线语义

看板严格模拟在线监测：**新选择一组数据时看不到任何数据**，各曲线从试验起点随回放生长，
任意时刻只能看到**当前时刻及之前**的信息：

- 主趋势图不预显未来曲线，已回放区带扫描光带与当前值读数标签；
- 多源子面板为滚动窗口，右端锁定当前时刻（前 600 s 从左向右生长，之后窗口滚动）；
- b2 扩展参考 / b3 断裂锚及其图例，仅在回放越过对应时刻后才出现；
- 三级预警灯与各级触发时刻，只在事件真实发生后才点亮 / 显示时间；
- 峰值 D、寿命进度、累计点数等统计量均按"当前时刻及之前"计算；
- 拖动进度条 = 只保留该时刻及之前的信息（等同于在该时刻重新开始观察）。

## 4. 数据包字段

> **数值数组可能是二进制编码的**：为减小体积，写包时把「纯数字列表」替换成
> `{"i16"|"i32"|"f32": "<base64>"}`（见 `shm/pkgcodec.py`），前端
> `dashboard.js hydrateAll()` 在加载后解成 `Int16Array`/`Int32Array`/`Float32Array`。
> 旧包（纯数组）仍可直接加载。`meta` / `warn` / `labels` / `chans` / `spec` 不编码。

```js

  foCols: ["s1",...,"s5"],         // 光纤通道 (无接入时面板显示"未接入")
  spec: {kind, load, note},        // 主样本：kind='已排除' 表示该组不参与建库/统计

          truncPct,                // ★ 预测中止的寿命%(null=未中止)，见下
          refs: [{pct, label}],    // 灰色参考竖线（主样本=预测中止点；L1 的论文检测点已下线）
```

**主样本的三条额外约定（2026-10-21）**

1. **001/002/015 已剔除**（用户裁定 2026-10-21）：三组**不进建库、不进统计、不出包**，

#### 4.1.1 `hiF`：论文 HI_F 离线参考（**已下线**）

> **2026-10-21 用户要求**：C1（`L1-03/04/05/09/23`）不再展示论文 `HI_F` 参考线与论文检测点。
> `l1/restore_dashboard_packages.py` 的 `tidy()` 会在每批导出后删除
> `hiF` / `meta.hiF85` / `meta.hiLeadPt` / `meta.refs`，因此重新生成也是干净的。
> 前端仍保留该图例的自动隐藏逻辑（`lgHI.style.display='none'`），旧包/旧截图仍可读。
> 下列字段与数值仅作历史留档。

L1 第一批（L1-03/04/05/09）曾额外携带论文的 `HI_F` 曲线，作为**灰色参考线**与主曲线同图对照：

| 字段 | 含义 |
| ---- | ---- |
| `hiF` | 论文 `HI_F` 逐帧序列（×1000 编码，`unit` = 归一化 0–1） |
| `meta.hiF85` | `HI_F` 首次达 0.85 的寿命百分比（`null`/缺省 = 寿命内未达） |
| `meta.hiLeadPt` | **主指标**相对 `HI_F` 的**提前量**（百分点，**正值 = 主指标更早**，`= hiF85 − t85(主指标)`） |

生成方式：导出器调用自己的正式实现 `reproduce_broer_l1.level4(gid)` 复算 `HI_F`，
再用 `np.interp` 插值到看板的 `cycle` 帧网格（`frameDt = 50`）。

**语义边界（务必按此理解）：**

- `hiF` 是**离线**量（依赖全寿命窗口 `T` 与事后归一化），**不是**在线可比：它与 `c0 基线终点`、
  `论文检测点`、`b3 断裂锚` 同属参考层；看板不把它当作第二套在线指标。
- 参考线**只在 L1 第一批出现**；主样本、L1 第二批（`L1-49…L1-60`，无 FBG）无此字段，
  前端检测到 `hiF` 为空即自动隐藏该图例与曲线（`lgHI.style.display = 'none'`）。
- 与其它曲线一致，参考线**只绘制当前时刻及之前**的部分，不预显未来（遵循 §2「在线语义」）。
- 图例文案由 `hiLeadPt` + `labels.legend` 动态生成，形如
  `论文 HI_F 参考（离线） · HI_hit 早 -3.1 个百分点`。
- **⚠️ 语义变更（2026-10-04）**：早先 `hiLeadPt` 是「**`D`** 相对 `HI_F` 的提前量」，
  老批 `l1` 主曲线改用**离线复评 `HI_hit`** 后，改为主指标相对 `HI_F` 的提前量。
  两者不可互换：`D` 与 `HI_hit` 的 0.85 时刻不同（`D` 因 BVID 起步即抬升，阈值到得早得多）。
  实测新值：L1-03 = **−0.7**、L1-04 = **−3.1**、L1-05 = **+1.7**、L1-09 = **−0.4** 个百分点
  （即 `HI_hit` 与论文 `HI_F` 的 0.85 时刻相差不超过 3.1 个百分点，
  而旧口径下 `D` 的提前量是 6.7 / 33.5 / 11.4 / 42.6 个百分点）。

#### 4.1.2 `labels`：主指标文案覆盖（可选）

各数据集的主指标名称不同（主样本 = `D(t)`，`l1v2` = `HI_AE`，`l1` / `l1v3` = `HI_hit`），
因此数据包可用 `labels` 覆盖界面文案；**未提供的键一律回落到 `index.html` 的原值**，
所以旧数据包（主样本、`l1v2` 早先版本）行为不变。

| 键 | 影响的元素 | 主样本默认值 |
| ---- | ---- | ---- |
| `legend` | 趋势图 D 系列图例 | `D(t)` |
| `unit` | 仪表下方单位行 | `损伤度 D` |
| `margin` | KPI「剩余裕度」标签 | `剩余裕度` |
| `thrName` | 分级预警三行的阈值标签 | `D` |
| `peak` | KPI「峰值」标签 | `峰值 D` |
| `foot` | 底部算法说明（支持 `{T}` 占位符） | `D ∈ [0,1] · 阈值 0.25 / 0.55 / 0.85` |
| `ae` / `fo` / `st` | 三个副面板标题 | 见 `index.html` |

另外 `indexName` / `trendName`（数据包顶层）分别覆盖 DAMAGE INDEX 标题与趋势面板标题。
`{T}` 占位符在 `foot` 与三级判定文案中会被替换成 `thrName`
（如 `HI_hit 越过 0.55，请安排停机检查`）。

清单：主样本用 `window.SHM_INDEX`（数组）；L1 用
`window.SHM_DATASETS['l1'] = {id, name, unit, path, groups:[...]}`。
前端 `collectDatasets()` 会把两者合并成顶栏「数据集」下拉（主样本优先）。

## 6. 与正式口径的一致性

- **主样本**：`D` 通道 = `dashboard/data/cdio/<gid>.js` 的**留一预测曲线**（`main/cdio_baseline/live_predictor.py`：
  CElog 时钟 + 组成指纹 KNN + 库容量贝叶斯 + 在线门控融合；模型工件 `model_bundle_final.pkl`），
  与 `main/results/cdio_summary.csv` 同源；`eae` / `est` 是 AE 与应变**各自**的归一化累计量，
  `risk` 取二者均值。阈值仅作**记录完成度分档**，不是损伤力学量、也不代表剩余寿命裕度。
- **L1**：主曲线 = `evaluate_l1_hi_ae.hi_of_group(gid)` 的 `HI = unity01(累积 AE hits)`（500 cycle 箱），
  与 `l1/results/l1_hi_ae.csv` 的 t85 同源（差异 ≤ 1 个百分点，来自 10-cycle 网格 → 50-cycle 帧的重采样）。
  论文检测点已下线（`meta.refs` 为空）。
- 看板**不重新训练、不引入未来信息**（主样本）；L1 主曲线本身是**离线复评**（`unity01` 用全寿命最大值），
  故界面对 L1 一律标注「离线复评（非在线）」，**不声称在线预警**。
- **论文 `HI_F` 灰色参考线（已下线）**：2026-10-21 起 C1 不再带 `hiF` / `hiF85` / `hiLeadPt`，
`restore_dashboard_packages.tidy()` 会在每次重建后删除这些字段。
  历史上它是由 `l1/reproduce_broer_l1.level4()` 复算的**离线参考层**，从不参与 `D`/`risk`/`lv` 计算。
- **C4 的 L1-30/34/36**：AE 窗口只覆盖全寿命的一小段（0.83 d / 12 min / 43 min），
  包内 `labels.foot` 带 ⚠ 声明，`meta.span_h/load_h/fbgWin` 给出具体窗口；
  **不得**与 C1/C2 的全寿命曲线并列做 t85 对比。L1-34 无 FBG 有效窗口（`fbgWin=0`、`nFo=0`）。
- **三级阈值 0.25 / 0.55 / 0.85 只是显示刻度**：主样本 = 进度分档，L1 = `HI` 分档；
  两者都**不承诺触发间隔**（受证据预算限制），也不承诺「0.85 = 已无剩余裕度」这类物理结论。
- **回放速率**：主样本 = `speed / frameDt`（`frameDt=0.5 s`，120× → 240 帧/s）；
  L1 无实时概念，改按**全长归一**（`4800/nfr`，120× 时全程 ≈ 40 s）。
- **DFOS 空间去尖峰（掉点修复）**：**全分辨率**逐块做「与局部中位(9 点窗)偏差 >
  `max(3000 µε, 8×1.4826MAD)`」判定，命中点用局部中位替换。
  实现位于 `evaluate_l1_dfos.despike_row`，**看板导出与 DFOS HI 指标共用同一判据与顺序**。
  ⚠️ 顺序要求：**先去尖峰、后补 NaN**（L1-04 矩阵约 9% 位置缺测，先插值会造出假尖峰）。
  修复点数：L1-03 **0** / L1-04 **7** / L1-05 **5** / L1-09 **273**，随包上报（`dfos.spikeN`）。
- **DFOS 热图色标**：取全寿命 |偏离| 的 **p98** 鲁棒归一（超出饱和），避免少数大偏离压平整幅图。
- **L1-04 提示**：其 FBG 应变几乎零漂移（−0.2 µε，见主 `README.md` §2.3(c)）⇒ D(t) 实际由 AE 单源主导，基线终点 `c0` 偏晚（42.8% 寿命）；AE 覆盖 99.9%，各面板均有数据。（其 AE 曾被认为仅覆盖 61.3%，那是 `.pridb` 时间基断裂的伪影。）
